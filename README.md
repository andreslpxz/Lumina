# Lumina AI Coding Agent IDE

This project is divided into two main components:
1. **Frontend**: A React web application.
2. **Backend**: A Python server providing an API and AI capabilities.

## Structure

- `frontend/`: Contains the React application.
- `backend/`: Contains the Python backend application.

## Getting Started

### Backend
To set up the backend:
1. Navigate to the `backend/` directory: `cd backend`
2. Create a virtual environment and install dependencies from `requirements.txt`.
3. Set up your `.env` file based on the provided `env.example`.
4. Run the backend server.

### Frontend
To set up the frontend:
1. Navigate to the `frontend/` directory: `cd frontend`
2. Install the necessary dependencies: `npm install`
3. Start the development server: `npm start`
